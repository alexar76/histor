# 一份工具列表要花多少钱

> 🌐 [English](tool-list-cost.md) · [Русский](tool-list-cost.ru.md) · [Español](tool-list-cost.es.md) · [Français](tool-list-cost.fr.md) · **中文**

客户端连接的每个 MCP 服务器都会列出自己的工具：每个工具有名称、描述和输入 schema。无论用户问什么，客户端都会把这份列表放进每一次模型请求的提示词里。我们 12,915 个软件包调查的一位读者（Paul Irolla）建议用 token 来算这笔账。HISTOR 保存着它观察到的每个服务器当前的工具列表，所以我们算了。

## 数字

2026-10-19 的快照：日志中至少有一个工具的每个软件包（npm、PyPI）和每个远程服务器，各取其当前列表。列表按客户端发给模型的样子计数：每个工具为紧凑 JSON 的 `{name, description, input_schema}`。分词器为 `o200k_base`（tiktoken 0.12，GPT-4o 系列）。

| | 软件包 | 远程服务器 |
|---|---|---|
| 服务器 | 18,204 | 16,170 |
| 工具定义 | 337,449 | 232,427 |
| 每台服务器的工具数：中位数 / 平均 / 第 90 百分位 | 8 / 18.5 / 40 | 7 / 14.4 / 31 |
| **每台服务器的 token：中位数** | **1,272** | **1,328** |
| 平均 | 3,812 | 3,412 |
| 第 90 百分位 | 8,361 | 7,425 |
| 第 99 百分位 | 39,612 | 22,294 |
| 最大 | 304,780 | 547,935 |
| 每个工具的 token：中位数 / 平均 | 129 / 206 | 231 / 237 |
| 超过 10,000 token 的服务器 | 1,447 | 618 |
| 超过 100,000 token 的服务器 | 31 | 9 |

平均数是中位数的三倍：少数拥有数百乃至数千个工具的服务器占了大部分 token。调查中"每台服务器约 24 个工具"是 2026-10-13 有应答的 7,656 个软件包的平均数；在今天更大的集合上，平均为 18.5，中位数为 8。

## 换算成钱

列表随每次请求重新发送，所以它的成本是 token × 单价 × 请求数。每 1,000 次请求，按 2026-10-19 的标价（OpenRouter）：

| 一台服务器的列表 | Token | 每百万 0.10 美元（Claude Haiku 5.5） | 每百万 2 美元（Claude Sonnet 5.5） | Sonnet 5.5，缓存读取（每百万 0.10 美元） |
|---|---|---|---|---|
| 中位数软件包 | 1,272 | 0.13 美元 | 2.54 美元 | 0.13 美元 |
| 平均软件包 | 3,812 | 0.38 美元 | 7.62 美元 | 0.38 美元 |
| 第 90 百分位 | 8,361 | 0.84 美元 | 16.72 美元 | 0.84 美元 |
| 第 99 百分位 | 39,612 | 3.96 美元 | 79.22 美元 | 3.96 美元 |

一个连接了五台中位数服务器的客户端，在用户说出第一个字之前就要发送约 6,400 个工具定义 token。最大的列表根本放不下：304,780 个 token 超过了 200,000 token 的上下文窗口。

有两件事能降低账单。提示词缓存：客户端让工具列表保持不变并放在提示词前部时，按 Sonnet 5.5 的标价，缓存读取只要二十分之一。以及按需加载定义：模型先只看到工具名称，准备调用某个工具时再拿到它的 schema。

## 这里没有测量什么

- **只用了一种分词器。** 不同模型分词方式不同，其他模型的计数会有差别，通常在几成之内；可以迁移的是形状：中位数在 1,300 token 左右，外加一条长尾。
- **服务商自己的文本。** 模型 API 会在定义周围加上自己的工具使用说明；这里没有计入。
- **客户端实际发送的内容。** 有的客户端会删掉字段或缩短长描述，有的还会发送输出 schema。如果按列出的完整定义计数，软件包列表的中位数为 1,390 token，第 90 百分位为 9,960。
- **人们实际使用哪些服务器。** 每个被列出的服务器只计一次：热门的和被弃用的权重相同。

## 复现

[`scripts/tool_list_tokens.py`](../scripts/tool_list_tokens.py) 读取当前工具列表的导出（查询语句在其 docstring 中）并写出摘要。我们的摘要（不含服务器名称）：[`tool-list-tokens-2026-10-19.json`](tool-list-tokens-2026-10-19.json)。
