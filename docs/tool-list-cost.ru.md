# Сколько стоит список инструментов

> 🌐 [English](tool-list-cost.md) · **Русский** · [Español](tool-list-cost.es.md) · [Français](tool-list-cost.fr.md) · [中文](tool-list-cost.zh.md)

Каждый MCP-сервер, к которому подключён клиент, перечисляет свои инструменты: у каждого имя, описание и схема
аргументов. Клиент кладёт этот список в промпт каждого запроса к модели, о чём бы ни спросил пользователь. Читатель
нашего опроса 12 915 пакетов (Paul Irolla) предложил посчитать это в токенах. HISTOR хранит текущий список
инструментов каждого сервера, который наблюдает, — мы посчитали.

## Числа

Снимок от 2026-10-19: каждый пакет (npm, PyPI) и каждый удалённый сервер в журнале, у которого есть хотя бы один
инструмент, со своим текущим списком. Список считается так, как клиент отправляет его модели: для каждого
инструмента `{name, description, input_schema}` в компактном JSON. Токенизатор — `o200k_base` (tiktoken 0.12,
семейство GPT-4o).

| | Пакеты | Удалённые серверы |
|---|---|---|
| Серверов | 18 204 | 16 170 |
| Определений инструментов | 337 449 | 232 427 |
| Инструментов на сервер: медиана / среднее / 90-й перцентиль | 8 / 18,5 / 40 | 7 / 14,4 / 31 |
| **Токенов на сервер: медиана** | **1 272** | **1 328** |
| среднее | 3 812 | 3 412 |
| 90-й перцентиль | 8 361 | 7 425 |

Среднее втрое больше медианы: основную долю токенов несут немногие серверы с сотнями и тысячами инструментов.
«Около 24 инструментов на сервер» из опроса — это среднее по 7 656 пакетам, ответившим 2026-10-13; на нынешнем,
большем наборе среднее 18,5, медиана 8.

## В деньгах

Список отправляется заново с каждым запросом, поэтому его цена — токены × цена × число запросов. На 1 000 запросов
по прайсу на 2026-10-19 (OpenRouter):

| Список одного сервера | Токенов | $0,10 за миллион (Claude Haiku 5.5) | $2 за миллион (Claude Sonnet 5.5) | Sonnet 5.5, чтение из кэша ($0,10 за миллион) |
|---|---|---|---|---|
| медианный пакет | 1 272 | $0,13 | $2,54 | $0,13 |
| средний пакет | 3 812 | $0,38 | $7,62 | $0,38 |
| 90-й перцентиль | 8 361 | $0,84 | $16,72 | $0,84 |
| 99-й перцентиль | 39 612 | $3,96 | $79,22 | $3,96 |

Клиент с пятью медианными серверами отправляет около 6 400 токенов определений инструментов ещё до первого слова
пользователя. Самые большие списки не помещаются вовсе: 304 780 токенов больше окна контекста в 200 000 токенов.

Счёт снижают две вещи. Кэш промпта — если клиент держит список инструментов неизменным и в начале промпта: по
прайсу Sonnet 5.5 чтение из кэша стоит двадцатую часть. И загрузка определений по требованию: модель сначала видит
только имена инструментов и получает схему, когда собирается вызвать этот инструмент.

## Чего это не измеряет

- **Один токенизатор.** Модели токенизируют по-разному, поэтому у других моделей счёт иной, обычно на десятки
  процентов; переносится форма — медиана около 1 300 токенов и длинный хвост.
- **Собственный текст провайдеров.** API модели добавляет вокруг определений свои инструкции по вызову
  инструментов; они не учтены.
- **Что клиенты отправляют на самом деле.** Одни выбрасывают поля или сокращают длинные описания, другие шлют и
  схему результата. Если считать определения целиком, как они перечислены, медиана пакета — 1 390 токенов,
  90-й перцентиль — 9 960.
- **Какими серверами пользуются.** Каждый сервер из реестров считается один раз: популярный и заброшенный весят
  одинаково.
