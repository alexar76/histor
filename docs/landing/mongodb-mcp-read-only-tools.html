Which MongoDB MCP tools disappear in read-only mode?

Enable read-only mode with --readOnly or MDB_MCP_READ_ONLY=true. To see which tools your client actually receives, compare its tools/list responses before and after.

What HISTOR and RugSnare observed

In archived comparisons of versions 3.0.5 and 3.1.0, HISTOR’s bare launch exposed nine additional write tools. RugSnare used --readOnly and a preconfigured connection.
